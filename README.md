# DeepHub AI – Maintenance Page

A clean, minimal, and professional "Under Maintenance" page for **DeepHub AI** created using simple, standard HTML, CSS, and JavaScript.

## Files

- [index.html](file:///home/ospoks/deephubai-maintenance/index.html): Clean maintenance message with platform status and support contact.
- [style.css](file:///home/ospoks/deephubai-maintenance/style.css): Vanilla CSS styling, responsive layout, dark theme matching DeepHub AI.
- [script.js](file:///home/ospoks/deephubai-maintenance/script.js): Minimal background connectivity check.
- [`assets/`](file:///home/ospoks/deephubai-maintenance/assets): DeepHub AI logo and favicon.

## How to View

Open `index.html` directly in your browser or run a simple local web server:

```bash
cd /home/ospoks/deephubai-maintenance
python3 -m http.server 8080
```
Then open `http://localhost:8080`
